## 功能范围

笔记面板顶部的 **中文 / EN** 提供 **简体中文** 与 **English**，默认中文。选择后立即刷新已打开的笔记面板，后续弹窗使用当前语言。界面、菜单、行图标提示、编辑器操作名称、笔记编辑窗口、导入导出预览和校验提示共用 211 条双语文案。

选择保存在 IDE 配置的 `options/reading-notes-settings.xml`，所有本地项目共用，重启后保留；项目笔记和分享格式不增加语言字段。已有标题、正文、主题与分组名称、源码、路径、稳定 ID 和绑定位置保持原样。新建的默认名称使用当前语言。IDE 和系统提供的通用控件使用各自的语言设置。
